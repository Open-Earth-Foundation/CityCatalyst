# CC-1311 re-score of Mirco's round 2 envelopes (2026-11-20)

These runs score the same envelopes as the CC-1295 study (`originals-v2/round2`, C-015 to C-025, 3 attempts each) at commit `df11e0909`. They show the effect of the CC-1311 approve changes:

- an unsplit subsector row (`I.3` with no scope) is now stored;
- a parent row is dropped when its child rows came too;
- `total_inclusion: excluded` is carried into `omitFromTotal`.

No model was called. Both runs are exploratory.

The per-attempt `results.json` and `extracted-values.json` files were removed before merge. They are in commit [`1933534e3`](https://github.com/Open-Earth-Foundation/CityCatalyst/tree/1933534e38386c4fe26260f2bbd3e5325e01bb3b/docs/ingestion-accuracy-runs).

## Reading the result

- **Totals.** The import change works on totals. The subsector values now reach the inventory: C-020 and C-024 pass their totals, the 10x misses fall from 8 to 1, and approve no longer fails.
- **The standard score does not see the gain.** The stored `I.3` row is scored against answer-key rows written as scoped children (`I.3.1`, scope 1) or as `I.3.x`. The scorer matches neither of those to a stored `I.3`. So a correct subsector value counts as one missing row plus one extra row. That is why recall stays at 68% and precision drops from 97% to 79%.
- **The variant now measures what is stored.** The parent refs variant writes a stored subsector row as `<ref>.x`. It matches what is now in the inventory, with no added rows and no double counting (the "children stored too" count is 0). It is no longer an upper bound.
- **Scorer decision.** Whether the standard score should accept a subsector-level value is a decision for the benchmark (a scorer change and a `SCORER_VERSION` bump). This ticket does not make that change.

Expected before the run (spec, control 5): C-020 at about 90% with its total within tolerance, C-021 at about 90%, C-023 and C-024 importing, and mean recall from 80% to 86%. The totals and the import errors behaved as expected. Recall reaches that range only with the variant, which shows the scorer gap above.
