    Two views of the same source
    With OCR on, PDFs are sent to Mistral before OpenAI starts. If you upload two PDFs, those OCR requests run in parallel with each other. OpenAI starts after preprocessing finishes. With JSON Schema, only the report needs OCR.
    The original PDFs and the structured OCR JSON are available side by side in the agent workspace. The agent can search extracted text and tables, then inspect original pages to check units, headers, and ambiguous values. OCR supplements the PDFs; it does not replace them or dictate which tool the agent must use.
    Context, loops, and debugging
    The agent receives file paths, page counts, the data definition, your prompts, and a required output contract. It reads context files as needed using its tools. Even with repair off, the agent can make many tool calls within its initial turn.
    Automatic repair adds a separate server-controlled loop after each completed turn. Invalid output, schema errors, missing reported coverage, and ambiguous, unreadable, or unsearched fields trigger feedback. A field marked “not found after search” remains an honest missing result. No repair may invent values to pass validation.
    Watch messages, commands, tool results, validation errors, repair counts, and reported usage in Agent activity. The server keeps looping while the browser is closed. OCR uses Mistral billing; agent work and repairs use OpenAI billing. OCR boxes stay in context; final evidence currently uses page numbers and quotes.
