# UA02-r3 — English review copy

Translation of the recorded Polish interaction. Scores come from revised-judgments.json, not the older translation summary. Missing transport is marked explicitly.

## Turn 1

**User**

I want to work on our city's inventory for 2024, but it looks as though that year is already in the system. Should I create it again, or can I continue the existing work?

**Climate Advisor**

If the inventory for 2024 already exists, it is best to **continue working in the existing one** — do not create a duplicate with the same city, year, inventory type, and GWP set.

Create a new inventory only when you deliberately need a separate version, e.g. for a different inventory type, a different GWP factor, or an independent scenario/methodology.

Before continuing, check the name, type, and GWP of the existing entry to make sure it is the correct record.

## Turn 2

**User**

I do not want to lose what has already been entered. How can I safely open that year and check what is in it?

**Climate Advisor**

To avoid losing data:

1. Go to the inventory list and **search for the city and the year 2024**.
2. Open the existing entry — **do not select the option to create a new inventory**.
3. Before editing, confirm it is the correct record: check **the inventory name, type, and GWP set used**.
4. In the inventory view, check sector status: which are already completed, which have gaps, and the available data sources.
5. Only then continue with the missing sections or those requiring corrections.

Simply opening the existing inventory should not delete previously entered data. If you see more than one entry for 2024, do not edit them blindly — compare the type, GWP, and name first.
