The draft-overview turn works because it injects the draft explicitly. Ask: refresh `document_context` (chapter titles + bodies or excerpts) after drafting completes, or give `cnb_chat` a `read_chapter`/`search_draft` tool like the edit planner has. Without this, the "ask Clima about the note" part of the demo only works for edit requests.
