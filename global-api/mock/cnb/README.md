# CNB Global API example

This folder shows a proposed Global API data structure for the Concept Note Builder, based on the Minnesota finance research.

- `funders.json` contains funding organisations.
- `funding-opportunities.json` contains programmes and funding cycles.
- `projects.json` contains project and applicant details.
- `project-funding.json` links projects to opportunities and records pipeline or award status.
- `funder-profile.json` contains reviewed eligibility, assessment criteria, document requirements, and supporting evidence for one funder.

These are draft examples to help agree the data structure and ownership with the data team. They are not implemented API responses or production data.
