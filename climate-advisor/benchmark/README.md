# Benchmark suites

`cnb/` is the Concept Note Builder benchmark: fixtures, judges, stage execution
and scoring, reports, viewer and saved runs. Start with
[cnb/benchmark.md](cnb/benchmark.md); [cnb/DELIVERY.md](cnb/DELIVERY.md) covers
the manual CI workflow and baseline approval.

`utils/` holds the OpenRouter usage recorder and usage models. It does not
import any CNB module.
