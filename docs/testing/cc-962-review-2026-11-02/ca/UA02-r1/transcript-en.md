Translation of the recorded Polish interaction. Scores come from revised-judgments.json, not the older translation summary. Missing transport is marked explicitly.

## Turn 1

**User**

I want to work on our city's inventory for 2024, but it looks as though that year is already in the system. Should I create it again, or can I continue the existing work?

**Climate Advisor**

Do not create a duplicate if the inventory for 2024 already exists. Open the existing entry and continue working in it.

Before starting, check that it matches the correct scope: city, base year, inventory type, and the GWP factor applied. It is worth creating a new inventory only if the current one concerns a different scope or methodology and should not be combined with your work.

## Turn 2

**User**

I do not want to lose what has already been entered. How can I safely open that year and check what is in it?

**Climate Advisor**

Open the existing inventory for 2024 — simply viewing it does not delete or overwrite data.

Safe procedure:

1. Go to the inventory list and select your city and the year **2024**.  
2. If you see more than one entry, compare their name, inventory type, and GWP used before opening one of them.  
3. Open the inventory and check the progress summary: which sectors are completed and which still require data.  
4. Review the data sector by sector. Until you save changes, you are not modifying existing entries.  
5. Before editing a specific field, note or copy the current value if you want a simple point of reference.

Do not create a new inventory just to check the contents of an existing one — this risks creating two parallel versions for the same year.
