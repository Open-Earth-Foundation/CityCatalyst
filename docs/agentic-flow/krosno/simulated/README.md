# Simulated files

Files a person in Krosno city hall would have to bring or request from a colleague, because the information is in no public document. They let a test run continue past the to-do list.

**None of these files exists yet.** This list says what each one would be. When they are written they must be marked as simulated on the first page, be built only from real Krosno data in the manifest, and name no person who is not already named in the public application.
